# SkyPro Music

_Учебный проект по frontend-разработке_

Веб-приложение для прослушивания музыки с персональным аккаунтом пользователя.  
Сервис позволяет просматривать каталог треков, управлять воспроизведением через встроенный плеер, добавлять композиции в избранное и изучать тематические подборки.

🚀 **Live Demo:** [https://skypro-music-phi.vercel.app/music/main](https://skypro-music-phi.vercel.app/music/main)

## Функциональность

- Регистрация и вход в аккаунт.
- Валидация полей форм и отображение ошибок API.
- Просмотр каталога треков и тематических подборок.
- Поиск и фильтрация треков.
- Музыкальный плеер: воспроизведение, пауза, переход к следующему и предыдущему треку, перемотка, регулировка громкости, повтор и случайный порядок воспроизведения.
- Добавление композиций в избранное и удаление из избранного.
- Обработка состояний загрузки и ошибок, отдельные страницы для ошибок и несуществующих маршрутов.

## Архитектурные решения

- **Глобальное состояние** реализовано с помощью React Redux. Redux хранит данные о треках, избранном, фильтрах, состоянии загрузки и ошибках.
- **Работа с API** вынесена в отдельный слой сервисов (src/services). Для выполнения HTTP-запросов используются Axios и Fetch API.
- **Маршрутизация** построена на Next.js App Router. Страницы и обработчики ошибок организованы в соответствии со структурой каталога src/app.
- **Компонентная архитектура** предполагает разделение интерфейса на переиспользуемые компоненты, расположенные в src/components.
- **Пользовательские хуки** вынесены в отдельный каталог src/hooks. Они позволяют переиспользовать логику работы с состоянием, API и пользовательскими действиями.
- **Стилизация реализована** с помощью CSS Modules, что обеспечивает изоляцию стилей компонентов. Для условного объединения CSS-классов используется библиотека classnames.
- **Типизация** реализована с помощью TypeScript. Типы данных и общие интерфейсы вынесены в отдельный каталог src/sharedTypes.
- **Тестирование** реализовано с помощью Jest и React Testing Library. Тесты позволяют проверять работу вспомогательных функций и компонентов.
- **Качество кода** поддерживается с помощью ESLint и Prettier, которые используются для выявления проблем и единообразного форматирования кода.

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/kors-ak/skypro-music.git
```

### Установка зависимостей

```bash
npm install
```

### Запуск проекта

```bash
npm run dev
```

Приложение будет доступно по адресу:

```text
http://localhost:3000
```

## Структура проекта

```text
src/
├── app/             # Страницы, layouts и обработчики ошибок Next.js
├── components/
│   ├── features/    # Основные UI-компоненты приложения
│   ├── initialization/ # Инициализация пользовательских данных и треков
│   └── loading/     # Компоненты состояний загрузки
├── hooks/           # Пользовательские React-хуки
├── services/        # Запросы к API и обработка авторизации
├── sharedTypes/     # Общие типы TypeScript
├── store/           # Redux store, slices и типизированные хуки
└── utils/           # Вспомогательные функции и их тесты
```
